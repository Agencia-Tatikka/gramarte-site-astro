# Gramarte • Paisagismo & Manutenção Condominial (Astro)

Repositório oficial do site institucional e landing page da **Gramarte**, construído sobre a arquitetura de alta performance **Astro + Tailwind CSS**.

## 🚀 Tecnologias
- **Framework:** [Astro v5](https://astro.build/)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
- **Deploy:** Cloudflare Pages / Static Hosting

## 📦 Comandos Disponíveis

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento (porta 4321)
npm run dev

# Gerar build de produção
npm run build

# Pré-visualizar build localmente
npm run preview
```

## 🌿 Identidade da Marca
- **Segmento:** Paisagismo e Manutenção de Áreas Verdes em Condomínios Residenciais.
- **Foco Geográfico:** São Paulo Capital, Grande ABC e Alphaville.
- **Proposta Única de Valor (UVP):** Cuidado técnico, equipe própria registrada (CLT), pontualidade e relatórios de acompanhamento.
